# 글 추천 토글 (Post Recommend)

## Parent

`.scratch/board/PRD.md`

## What to build

회원이 글에 보내는 1인 1회 추천(토글). 다시 누르면 취소되고, 본인이 쓴 글도 추천할 수 있다. 글 상세에 현재 추천수가 표시된다.

- **PostRecommend** 엔티티: (Member, Post) 한 쌍당 1행. 행 존재 = 추천 상태, 행 수 = 글 추천수.
- 추천 액션: 해당 행이 없으면 생성, 있으면 삭제(토글). 본인 대상 제한 없음.
- 비로그인으로 추천 시도 시 로그인으로 유도.
- 추천수는 추천 행 집계로 노출(별도 카운터 비정규화는 비범위).

## Acceptance criteria

- [ ] 회원이 글을 추천하면 추천수가 1 증가하고 추천 상태로 표시된다
- [ ] 이미 추천한 글을 다시 누르면 추천이 취소되고 추천수가 1 감소한다
- [ ] 한 회원이 같은 글을 여러 번 눌러도 집계는 최대 1로 유지된다
- [ ] 본인이 쓴 글도 추천할 수 있다
- [ ] 비로그인으로 추천 시도 시 로그인으로 유도된다
- [ ] 위 동작을 검증하는 MockMvc 통합 테스트가 통과한다(추천, 취소, 중복 무효, 본인 추천, 비로그인 유도)
