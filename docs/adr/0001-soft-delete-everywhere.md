# 전면 소프트 삭제 (Soft Delete)

회원·글·댓글을 모두 소프트 삭제(`deleted` 플래그)로 처리한다. 하드 cascade 삭제 대신 이 방식을 택한 이유는, 삭제된 댓글을 "삭제된 댓글입니다" 자리표시로 남겨 대댓글의 맥락을 보존하고, 탈퇴 회원의 글·댓글을 작성자명 "탈퇴한 회원"으로 그대로 유지하기 위해서다.

## Consequences

- 모든 목록·상세·집계 쿼리는 `deleted = false`를 기본 필터로 깔아야 한다(누락 시 삭제 데이터 노출).
- 삭제된 글은 목록·상세에서 완전히 숨기지만, 삭제된 댓글은 자리표시로 노출한다 — 글과 댓글의 노출 규칙이 다르다.
- username·nickname 유니크 제약이 소프트 삭제 레코드에도 그대로 적용되어, 탈퇴한 식별자는 재사용할 수 없다.
